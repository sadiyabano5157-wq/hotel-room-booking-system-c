# hotel-room-booking-system-c
C program to calculate hotel room charges and discount using if-else conditions.

# Hotel Room Booking System in C

This C program calculates:
- room charges
- discount
- final hotel bill

based on:
- room type
- number of days

using if-else conditions.

## Features
- AC and Non AC rooms
- Discount for more than 3 days stay

## Concepts Used
- if-else
- percentage calculation
- user input
